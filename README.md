# Branch Toppers Analysis Using Python

## Objective
Analyze student topper data to find highest percentage, average percentage, branch-wise performance, and visualize the results.

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Calculated average percentage
- Found highest percentage
- Year-wise topper count
- Branch-wise average percentage
- Sorted top students
- Visualized data using bar chart

## Conclusion
This project analyzes student topper performance across different branches and years using Python.
